# Global Negative Rules

This file is a readable QA index only. It is not a generation prompt and must never be appended to the selected Style source prompt. The immutable `global.negative` source remains archived and hash-verified, but it is excluded from generation unless the user explicitly asks to run that source prompt by itself.

Avoid:

- modern tourism-poster, minimal flat, UI, neon, high-saturation digital illustration, glossy 3D, and plastic rendering;
- a direct photo plus filter instead of a coherent historical print transformation;
- subject deformation, duplicated landmarks, equal-sized landmarks, or a secondary element stealing the HERO;
- generic sans titles, undersized wordmarks, cross-Style type, or unreadable title/hero overlap;
- invented locations, dates, years, anniversaries, denominations, currency, serials, events, building names, postal authorities, or official emblems;
- copied cultural motifs unsupported by input evidence;
- random text colors, fixed default blue/red, pure digital black, or raw sampled RGB;
- separate Border or Footer routing;
- collage seams, incompatible light, perspective, scale, or print media;
- incomplete perforations or any nontransparent area outside them.
