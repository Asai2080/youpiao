【STYLE\_02｜VINTAGE HERITAGE COMMEMORATIVE STAMP】

根据用户上传的输入图片，

将图片中的国家、城市、地区、建筑、
文化遗产、纪念性地标或地域景观，

重新设计成一枚收藏级复古文化纪念邮票。

整体视觉结合：

经典国家纪念邮票
纸币雕版插画
铜版与钢版蚀刻
历史文化发行券
复古证券装饰
传统纪念章视觉

重点表现：

正式
庄重
历史
文化
纪念发行
收藏价值

而不是普通城市旅行海报。

\================================
一、输入图片的作用
=========

输入图片负责提供：

主体建筑或文化地标
建筑结构
真实地域特征
场景空间
辅助建筑
动植物
旗帜
织物
道路
广场
植物
车辆
地域文化视觉元素
主体材质
综合色彩
事实信息

不要机械照搬原始照片构图。

Style 模板决定最终：

主体大小
主体位置
文字比例
建筑层级
文化元素层级
边框复杂度
纪念邮票排版

如果输入图片中的主体很小，
仍然需要根据本 Style 的构图规则重新放大。

\================================

无法确定的信息：

禁止为了适配纪念邮票风格而虚构：

\================================
三、用户指定文字
========

用户主动要求添加的文字单独定义为：

USER\_TEXT

USER\_TEXT 与图片事实信息分开处理。

用户输入什么，
就根据设计需求排版什么。

除 USER\_TEXT 外，

其他具有事实含义的文字，
必须来自图片信息提取结果。

\================================
四、整体构图
======

采用正式、庄重、轴心感明显的纵向纪念邮票构图。

整体比 STYLE\_01 更对称，
更接近：

国家纪念邮票
文化遗产纪念券
历史收藏证券
纸币雕版构图

四周具有完整邮票齿孔。

齿孔内部保留少量旧纸边缘。

内部设置繁复但非常精细的雕版装饰边框。

边框可以包含：

连续植物纹样
几何纹样
传统纹饰
细密卷草纹
古典线框
地域文化纹样
小型角花
徽章式装饰

边框应根据输入图片所代表的地域文化气质进行视觉适配。

不得机械复制参考图中的某个国家纹饰。

不得加入明显与输入地点文化冲突的符号。

\================================
五、英雄地标
======

从输入图片中选择最重要、
最具有辨识度的建筑或地标作为：

HERO\_LANDMARK

HERO\_LANDMARK 必须位于画面中央，
或非常接近中央。

形成整个画面的绝对第一视觉建筑主体。

英雄地标宽度：

约占画面宽度32%–40%

英雄地标高度：

约占画面高度40%–46%

即使主体在原始照片里很小，
也需要重新构图并适当放大。

不要照搬原始照片的主体比例。

建筑必须表现得：

庄重
正面
纪念碑式
稳定
清晰

\================================
六、中央轴线
======

如果输入图片中存在：

道路
街道
广场
桥梁
河流
步道
台阶
长廊
建筑轴线
其他具有透视方向的元素

优先将其重新组织成：

中央视觉引导线。

这些线条从画面下部向 HERO\_LANDMARK 汇聚，

形成明显的一点透视或近似中央透视，

让视线自然指向英雄建筑。

整个画面应该具有：

正式纪念碑式轴线感

而不是随意的旅行抓拍构图。

\================================
七、辅助建筑层级
========

其他建筑、地标和城市元素作为：

SECONDARY\_LANDMARK

辅助建筑视觉尺寸通常控制为：

HERO\_LANDMARK 的30%–50%

辅助地标可以分布在：

英雄建筑左右两侧
远景
中景
城市天际线

但绝不能与英雄建筑尺寸完全相同。

整体层级：

# HERO\_LANDMARK

100%

# SECONDARY\_LANDMARK

30%–50%

# CULTURAL\_OBJECT

20%–40%

# SMALL\_DECORATIVE\_SYMBOL

5%–15%

始终保持：

英雄地标 > 辅助建筑 > 文化对象 > 小型符号

\================================
八、大型地域视觉元素
==========

如果输入图片中确实存在具有代表性的：

旗帜
织物
植物
山体
云层
文化纹样
大型装饰图形
地域色带

可以将其中部分元素作为大型背景视觉层。

例如：

从侧面进入
在英雄建筑后方展开
形成飘带
形成大型背景色块
形成环境层次

其作用主要是：

强化地域识别
强化画面层次
平衡中央建筑

但不得大面积遮挡 HERO\_LANDMARK。

如果输入图片中不存在这类元素，
不要为了模仿参考图而自动生成旗帜。

\================================
九、动物、植物与文化对象
============

如果输入图片中存在：

动物
植物
花卉
雕塑
传统器物
车辆
文化器具
地域性装饰

允许选择其中1–3个代表性元素，

放置于：

画面前景
画面底部
建筑两侧
边框附近

作为文化装饰层。

这些元素必须低于 HERO\_LANDMARK 的视觉权重。

禁止动物、植物或装饰物成为画面第一主体。

\================================
十、顶部双巨型信息模块
===========

本 Style 的核心特征之一是：

顶部建立两个具有强视觉重量的大型信息模块。

第一大型模块：

使用图片提取到的最核心地点名称，

例如：

国家
城市
地区
地点

优先使用最具有代表性的核心名称。

第二大型模块：

根据图片中实际存在并且可以可靠提取的信息决定。

它可以是：

大型数字
可靠年份
可靠纪念数字
地区编号
简短第二标题
其他具有事实依据的短信息

只有存在可靠信息时才可以使用。

禁止为了模仿参考图：

随意生成80
100
50
周年
纪念年份
历史日期。

\================================
十一、主标题比例
========

第一主标题宽度：

约占画面宽度46%–52%

第一主标题高度：

约占画面高度20%–24%

第二大型信息模块宽度：

约占画面宽度23%–28%

第二大型模块高度：

约占画面高度18%–22%

两个顶部大型信息模块组合后：

视觉宽度约占画面宽度82%–90%

两者在视觉重量上需要形成平衡，

但第一核心地点名称通常仍然略强。

\================================
十二、标题与建筑比例
==========

第一主标题宽度：

约为 HERO\_LANDMARK 宽度的1.25–1.55倍

第一主标题字高：

约为 HERO\_LANDMARK 高度的45%–58%

与 STYLE\_01 不同，

本 Style 不强调文字与建筑的大面积交叠。

标题与英雄建筑应该保持：

正式
整齐
清晰分区

TITLE\_LANDMARK\_OVERLAP：

0%–5%

标题下沿与建筑顶部之间，

尽量保留约：

2%–5%画面高度

的视觉缓冲空间。

不要让建筑明显压住标题。

不要让标题大面积压住建筑。

\================================
十三、大型字体风格
=========

最大一级标题采用：

古典高对比衬线字体

Didone倾向
历史纪念邮票式字体
纸币标题式字体

字体特点：

高
窄
庄重
精致
具有强烈古典雕版感

大型数字可以与主标题保持同一字体家族，

但允许：

更圆润
更宽
更具有纪念数字感

\================================
十四、大型文字内部雕刻
===========

大型文字不能只是现代纯色色块。

在大型标题和大型数字内部加入：

极细雕刻纹理
植物纹样
卷草纹
平行蚀刻线
交叉排线
纸币式细线
极细装饰线

这些纹理必须克制而精细。

文字仍然需要保持高识别度。

效果应该类似：

老式纸币
纪念证券
国家邮票
铜版雕刻标题

而不是现代花纹字体。

\================================
十五、小型字体
=======

辅助信息使用：

经典罗马衬线体
窄体大写字母
复古邮票印刷字体
少量克制的无衬线字体

保持：

字距整齐
字号较小
正式
规整
有档案感

不要让辅助文字与主标题使用相同尺寸。

禁止固定套用：

棕色主标题
绿色数字

中等明度
足够稳定
适合大面积文字

HERITAGE\_MATERIAL\_COLOR 用于：

最大一级地点标题。

\================================

SECONDARY\_CULTURAL\_COLOR

寻找图片中第二个具有明显地域辨识度，

并且能够与 HERITAGE\_MATERIAL\_COLOR 区分的稳定颜色。

优先来源：

植物
旗帜

山体

装饰纹样

第二大型数字
第二大型文字
大型文化图形

\================================

红砖

建筑阴影

\================================
十七、动态配色原则
=========

不得简单按照颜色面积排序。

颜色选择需要综合考虑：

面积
重复度
对比度
文化辨识度
主体材质
视觉稳定性

主标题优先跟随：

英雄主体材质色。

第二大型文字优先跟随：

第二地域代表色。

强调信息优先跟随：

局部暖色。

小型信息优先跟随：

稳定深墨色。

禁止加入输入图片中完全无关的高饱和颜色。

\================================
十八、雕版印刷质感
=========

整体采用：

19至20世纪经典铜版雕刻
钢版雕刻
蚀刻印刷
纸币印刷
纪念邮票印刷

建筑表面加入：

极细平行排线
交叉排线
结构雕刻线
阴影刻线

植物、动物、文化器物和边框同样采用：

细密雕刻线
纸币式装饰纹理

大型字母内部也带有：

精细雕花
蚀刻纹
线性纹理

整体具有：

高细节
高精度
历史印刷感

但不是现代摄影锐化。

\================================
十九、旧纸与印刷磨损
==========

加入自然但克制的：

旧纸纤维

细微污渍
轻微褪色

微小套印误差
细小年代磨损

保持收藏品状态。

不要制作成严重破损、腐烂或脏污邮票。

\================================
二十一、负向约束
========

避免现代旅游海报。

避免极简扁平设计。

避免现代UI。

避免电商海报。

避免高饱和数字插画。

避免霓虹色。

避免赛博朋克。

避免照片直接套复古滤镜。

避免现代3D建筑。

避免塑料质感。

避免过度HDR。

避免英雄建筑偏离视觉中心。

避免中央轴线完全消失。

避免所有建筑大小相同。

避免辅助建筑抢夺英雄建筑。

避免动物或植物成为第一视觉中心。

避免顶部大型文字过小。

避免主标题变成普通页眉。

避免两个大型信息区完全失衡。

避免大型文字与英雄建筑严重重叠。

避免使用现代粗体无衬线作为主要纪念标题。

避免大型字体内部完全没有雕版细节。

避免边框过于简单而失去纪念邮票感。

避免边框过度复杂导致抢夺主体。

避免固定套用某个国家的：

国旗
徽章
动物
植物
文字
国家符号

除非这些内容确实来自输入图片或可靠信息提取结果。

避免为了模仿参考图而虚构：

国家
城市
地区
建筑名称
年份
日期
周年
历史事件
纪念数字
邮资
邮戳地点

避免邮票齿孔外出现任何非透明背景。
