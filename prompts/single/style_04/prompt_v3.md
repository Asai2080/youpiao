【STYLE\_04｜VINTAGE CULTURAL CITYSCAPE POSTER STAMP】

复古文化城市生活旅行邮票

根据用户上传的输入图片，

将其中的城市、地区、传统建筑、
历史地标、湖泊、河流、桥梁、
街道、城市生活、植物以及其他具有地域文化特征的场景，

重新设计成一枚真正具有历史收藏感的
20世纪早中期复古文化城市旅行邮票。

整体视觉严格结合：

1920s–1950s 复古城市旅行邮票
20世纪早期欧洲与亚洲旅行海报
老式彩色石版印刷

几十年前真实设计、
真实印刷、
真实发行，

文化城市纪念旅行邮票。

\==================================================
三、整体构图逻辑
========

本 Style 不是：

单一英雄建筑纪念邮票。

也不是：

线性桥梁或道路旅行邮票。

本 Style 的核心是：

超大型城市字标

-

多地标文化城市组景

-

大型植物枝条穿插标题

-

远近城市时间层级

-

地方生活叙事元素。

整个邮票呈现：

上部以文字为主

下部以城市文化景观为主。

形成明显的：

上字
\+
下景
\+
植物穿字

的经典旅行邮票构图。

\==================================================
五、超大型城市名称
=========

如果能够可靠提取：

则将其作为：

标题宽度约占邮票内框宽度：

82%–87%。

标题高度约占邮票内部高度：

28%–32%。

# TITLE\_WIDTH\_RATIO

0.82–0.87

# TITLE\_HEIGHT\_RATIO

0.28–0.32

标题必须明显大于：

任何一栋单独建筑

任何人物

任何辅助文字。

大型地点名称不是普通标题。

它必须成为：

整张邮票的第一核心平面设计元素。

→

→
土橙 / 锈橙。

最终得到：
